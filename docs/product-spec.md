# プロダクト仕様

## 1. サービス概要

`japan-travel-phrases` は、日本を旅行する外国人が、旅行中の場面と具体的な困りごとを選び、その解決に必要な日本語だけをすぐ使えるようにするフレーズ学習・提示サービスである。5カテゴリそれぞれ5問題、合計25問題のフレーズを提供する。

## 2. 解決する課題

一般的なフレーズ集では、緊張や時間制約がある状況で適切な表現を探すまでに時間がかかる。また、日本語を読めない利用者は、意味、発音、駅員への伝え方を別々に調べる必要がある。本サービスは、問題を入口にして必要な情報と操作を一箇所へまとめる。

本サービスは緊急通報・救命・災害対応を目的とする緊急サービスではない。

## 3. 対象ユーザー

- 日本旅行中または旅行予定で、日本語での会話に不安がある外国人
- スマートフォンを使って旅行中の場面で短時間に問題を解決したい人
- 英語で意味を確認し、ローマ字または画面提示で日本語を伝えたい人

## 4. 提供価値

- 問題を選ぶだけで、関連する3〜5件の日本語フレーズへ到達できる。
- 日本語、ローマ字、英訳を同時に確認できる。
- 発話が難しい場合は、大きな日本語をスタッフへ直接見せられる。
- ログインや入力を求めず、旅行中に迷いにくい。

## 5. 扱うカテゴリと問題候補

### Train & Station

1. 改札から出られない
2. 間違った電車に乗った
3. 正しいホームが分からない
4. ICカードの残高が足りない
5. 電車に忘れ物をした

各問題の公開用英語タイトル、slug、説明、3件のフレーズを静的データとして追加する。日本語、ローマ字、英訳は2026-08-05にプロジェクトオーナーが確認済みである。

### Airport

1. チェックインカウンターが見つからない
2. フライトが遅延・欠航している
3. 預け荷物が見つからない
4. 保安検査で問題が起きた
5. 搭乗ゲートが見つからない

### Restaurant

1. 注文を手伝ってほしい
2. 食物アレルギーがある
3. 注文と違う料理が来た
4. ベジタリアン向け料理が必要
5. 会計をしたい

### Hotel

1. チェックインできない
2. 部屋に問題がある
3. 荷物を預けたい
4. 部屋に入れない
5. チェックアウトを手伝ってほしい

### Shopping

1. 商品が見つからない
2. 別のサイズ・色が必要
3. 値段を確認したい
4. 免税で購入したい
5. 返品・交換したい

追加4カテゴリにも各問題3件の日本語、ローマ字、英訳、スタッフ向け表示を提供する。2026-08-11に初期データを追加し、公開前に人間が自然さ、正確さ、状況適合性を確認する。

## 6. 基本利用フロー

1. 利用者がトップページでサービスの目的と注意書きを確認する。
2. `Find a phrase` を押して場面選択へ移動する。
3. 5カテゴリから場面を選んで問題一覧へ移動する。
4. 該当する問題カードを選択する。
5. 問題詳細で日本語、ローマ字、英訳を確認する。
6. 必要に応じて `Show to staff` でスタッフ向け表示を開く。

トップページからフレーズ確認までは3操作以内、問題一覧からは1操作で到達することを目標とする。

## 7. MVPの成功条件

- 25問題すべてが一覧から選択でき、対応する詳細ページを表示できる。
- 各問題で3〜5件の確認済みフレーズが表示される。
- 各フレーズのスタッフ向け表示がスマートフォンで利用できる。
- 初見の利用者が説明なしで目的のフレーズへ2〜3操作以内に到達できる。
- 主要機能が375px前後の画面、GitHub上のソース、Vercel本番環境で正常に動作する。
- サービスが緊急サービスではないことをトップページで認識できる。

## 8. MVP対象外

- 音声再生
- バックエンドAPI、データベース、認証、課金、CMS
- AI会話、発音判定、ユーザー向けリアルタイムAI API呼び出し
- お気に入り、履歴、検索、ユーザー投稿、多言語UI、オフライン対応
- Docker、AWS

最後の4項目（お気に入り等）は将来候補になり得るが、MVP要件には含めない。
